# THE HOLLY fan site

Görsellerden hazırlanmış, GitHub Pages'e yüklenebilir tek sayfalık site.

## Linki değiştirmek

`index.html` dosyasını aç. En altlardaki şu satırı bul:

```js
const GROUP_URL = "https://www.roblox.com/communities/161344644/The-Holly";
```

Tırnakların içindeki adresi kendi **resmi Roblox grup/topluluk** bağlantınla değiştir. Güvenlik için yalnızca `roblox.com` ve `www.roblox.com` adreslerindeki grup/topluluk bağlantıları çalışır; `roblox.com.ss` Roblox'un resmi alan adı değildir.

## GitHub Pages'e yükleme

1. GitHub'da yeni bir public repository oluştur.
2. Bu klasördeki `index.html`, `background.jpg` ve `roblox-logo.png` dosyalarını repository'nin kök dizinine yükle.
3. Repository **Settings > Pages > Build and deployment > Deploy from a branch** bölümüne gir.
4. `main` branch ve `/ (root)` seç, ardından **Save** de.
5. GitHub Pages sayfana oluşturulan adresten ulaşabilirsin.

Bu sayfa Roblox'la bağlantılı olmayan bir hayran topluluğu sayfasıdır, resmi Roblox giriş veya bot doğrulama sayfası değildir.
